# Seen from space

Night-lights growth over three data center regions, from NASA GIBS. See "Seen from space" in the top-level README.

- `nasa_lights.py`: picks the layer from GIBS capabilities, averages the clearest June–August nights in the first and latest full years, caches the images, computes brightness and growth
- `test_space.py`: offline tests (network blocked)
- `cache/`: gitignored; built on first use
